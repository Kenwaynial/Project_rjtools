# RJ Tools

RJ Tools is a simple collection of web-based utilities designed to help with everyday calculations and small tasks. It focuses on providing fast, practical, and easy-to-use tools in a clean interface.

This project was built to improve my skills in web development and to create useful tools that solve real-world problems in a simple and accessible way.

---

## Features

- Collection of simple utility tools  
- Fast and lightweight interface  
- Clean and minimal design  
- Works across different devices  

---

## Purpose

This project was created for my dad to help him with practical calculations and everyday work tasks. It also serves as a learning project for me to improve my web development skills while building something useful in real life.

---

## Built With

- HTML / CSS / JavaScript
- Deployed on Vercel
